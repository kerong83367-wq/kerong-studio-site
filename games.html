About Kerong Arcade

Kerong Arcade is a small collection of free browser games made by Kerong Studio. Every game here is written from scratch in plain HTML, CSS and JavaScript, so it loads fast and runs on almost any device — phones, tablets, Chromebooks and PCs. There is nothing to install and no account to create.

New games are added over time. If you have a favorite classic you'd like to see here, send us an email and we might build it next.
